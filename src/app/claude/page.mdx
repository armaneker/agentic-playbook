# Claude

Guides for Claude Code, Anthropic's coding agent: how to configure it, extend it, and make it check its own work.

Claude Code is an agent harness in the sense of the [Concepts](/concepts/agent) pages. The model is Claude; the harness is the CLI, its tools, its permission system, and the settings files you control. Most of what you can change about its behavior lives in those settings files, and this section covers them one feature at a time.

## Pages

- [Hooks](/claude/hooks) — Commands Claude Code runs at fixed points in a session. Exit codes, the Stop hook that makes Claude fix failing tests, and how to keep it from looping.
